# Video script — branded human cut

English narration uses the existing ElevenLabs `Damien Voice` clone with its recommended Eleven Multilingual v2 defaults. The edit follows one chronological capture and includes a visible cursor. No tempo or pitch stretching.

## 0:00–0:09 — Hook

Most automation demos stop at “done.” ArcadeOps asks two more questions: who decided, and what proves the result?

## 0:09–0:20 — Inspect

This is Project Aurora, a release due tomorrow. A browser operator can use seven native WebMCP actions to inspect the real workspace — not scrape the screen. One validation is blocked. Production changes and outside contact are forbidden.

## 0:20–0:33 — Plan and delegate

The operator prepares a bounded mission. The plan appears here, with dependencies, a hard cost cap, and four evidence checks. Then it delegates one persisted run to the release worker.

## 0:33–0:50 — Human decision

ArcadeOps stops at the decision that actually matters: stage with documented residual risk, or postpone. The software explains both outcomes, but it cannot choose for me. I select staged release.

## 0:50–1:00 — Resume

The same signed run resumes. The worker produces the release summary and rollback plan, without touching production.

## 1:00–1:09 — Proof

Now the proof. Four checks pass. I accept this exact evidence pack. Relay issues a signed certificate and verifies it.

## 1:09–1:12 — Closing

The operator delegated. I decided. ArcadeOps kept the evidence.
